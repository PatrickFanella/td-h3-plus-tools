# TD-H3 Plus Tools

Channel plans and repository-specific tooling for the Tidradio TD-H3 Plus.

Start with the [60515 configuration guide](TD-H3-PLUS-60515-GUIDE.md) for the
recorded device state, profile definitions, driver limitations, and readback
evidence. The JSON plans are source inputs; the guide distinguishes them from
verified device uploads.

The `tools/` directory includes helpers and a retained CHIRP driver under
`tools/vendor/`. Preserve its upstream attribution and GPL-2.0-or-later header.
Generated images, device backups, and upload/readback receipts remain outside Git.
